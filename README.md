\# Flask ToDo (SQLite)



シンプルな Flask + SQLite の ToDo アプリです。  

ユーザーがタスクを追加・一覧表示・削除できます。





\## 主要技術

\- Python 3.10+

\- Flask

\- SQLite3

\- Bootstrap 5



\## セットアップ

```bash

python -m venv venv

venv\\Scripts\\activate   # Windows

pip install -r requirements.txt

python app.py

\# ブラウザで http://127.0.0.1:5000
